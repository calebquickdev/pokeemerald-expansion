# Plan 01-03: UpdateDynamaxDens Hook and Species Stub

## Goal
Implement `RollDynamaxDenPokemon()` (placeholder stub) and `UpdateDynamaxDens()`, then wire `UpdateDynamaxDens()` into `UpdatePerDay()` in `src/clock.c` so den species re-roll every midnight.

## Context

**Prerequisite:** Plan 01-02 must be complete. `include/raid_den.h` declares both functions and defines `struct DynamaxDen`, `MAX_DYNAMAX_DENS`. `include/global.h` includes `raid_den.h` and `SaveBlock2` contains `dynamaxDens[MAX_DYNAMAX_DENS]`.

**`UpdatePerDay()` in `src/clock.c`** (lines 38–60):
```c
static void UpdatePerDay(struct Time *localTime)
{
    u16 *days = GetVarPointer(VAR_DAYS);
    u16 daysSince;

    if (*days != localTime->days && *days <= localTime->days)
    {
        daysSince = localTime->days - *days;
        ClearDailyFlags();          // <-- add UpdateDynamaxDens call after this line
        UpdateDewfordTrendPerDay(daysSince);
        // ... other daily updates ...
        *days = localTime->days;
    }
}
```
Add `UpdateDynamaxDens(daysSince);` immediately after `ClearDailyFlags();`. The `daysSince` parameter (u16) is in scope and handles multi-day skips.

**`clock.c` already includes `global.h`** (line 1), which transitively includes `raid_den.h` after Plan 01-02, so `UpdateDynamaxDens` will be declared without a new include.

**`RollDynamaxDenPokemon` stub behavior:**
- Phase 1 is a foundation stub — it always returns `SPECIES_RALTS` regardless of `denId`
- Real species pool logic comes in a later phase
- `SPECIES_RALTS` is available from `constants/species.h` (included transitively via `raid_den.h` → `constants/species.h`)

**`UpdateDynamaxDens` behavior:**
- Iterates over all `MAX_DYNAMAX_DENS` dens
- For each den `i`: calls `RollDynamaxDenPokemon(i)` and stores result in `gSaveBlock2Ptr->dynamaxDens[i].species`
- Sets `gSaveBlock2Ptr->dynamaxDens[i].isGmax = 0` (stubs to no Gigantamax in Phase 1)
- `daysSince` parameter is accepted for API compatibility with future multi-day logic but is unused in Phase 1 (mark with `(void)daysSince;` to suppress warnings)

**New source file:** `src/raid_den.c`
- Include `global.h` and `raid_den.h`
- No other includes needed for Phase 1

**GBA constraints:** No malloc, no printf, no recursion. Use a simple `for` loop. Access save data via `gSaveBlock2Ptr`.
