# Plan 01-01: Daily Den Raided Flags

## Goal
Add a `FLAG_DAILY_DEN_RAIDED(denId)` macro that maps 20 den IDs to contiguous unused daily flags, and create the `include/raid_den.h` header that all future raid den code will include.

## Context

**Flag system:**
- Flags live in `gSaveBlock1Ptr->flags[]` (SaveBlock1, not SaveBlock2)
- Daily flags range: `DAILY_FLAGS_START = 0x920`, `DAILY_FLAGS_END = 0x95F` — 64 total flags
- `ClearDailyFlags()` in `src/event_data.c` does a `memset` across the entire DAILY_FLAGS byte range, so den flags are automatically cleared at midnight with no extra code needed
- The 20 contiguous unused slots begin at `FLAG_UNUSED_0x935` which is `DAILY_FLAGS_START + 0x15`
- Flags `FLAG_UNUSED_0x935` through `FLAG_UNUSED_0x948` are the 20 slots (offsets 0x15–0x28)

**Macro arithmetic:**
```c
// denId must be 0–19
#define FLAG_DAILY_DEN_RAIDED(denId)  (DAILY_FLAGS_START + 0x15 + (denId))
```
`DAILY_FLAGS_START + 0x15` = `FLAG_UNUSED_0x935` (the first available slot).

**`MAX_DYNAMAX_DENS` value:** 20

**Header guard pattern** (follow existing headers in `include/`):
```c
#ifndef GUARD_RAID_DEN_H
#define GUARD_RAID_DEN_H
// ...
#endif // GUARD_RAID_DEN_H
```
