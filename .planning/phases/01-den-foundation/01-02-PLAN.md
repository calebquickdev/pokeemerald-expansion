# Plan 01-02: SaveBlock2 Den Storage

## Goal
Add `struct DynamaxDen` and `dynamaxDens[MAX_DYNAMAX_DENS]` to the end of `SaveBlock2` so each den's species and Gigantamax flag persist across save/load cycles.

## Context

**SaveBlock2 location:** `include/global.h` lines 533–572

**Current last field** (line 571):
```c
    u32 randomizerSeed;
}; // sizeof=0xF2C
```

**Size constraint:**
- `SECTOR_DATA_SIZE = 3968` bytes (`include/save.h` line 5)
- Current `sizeof(SaveBlock2) = 0xF2C = 3884` bytes → 84 bytes free
- `struct DynamaxDen` must be exactly 4 bytes: `u16 species` (2) + `u8 isGmax` (1) + `u8 _pad` (1) = 4
- 20 dens × 4 bytes = 80 bytes → fits within 84 free bytes
- A `STATIC_ASSERT` in `src/save.c` line 82 will fail at compile time if the struct exceeds 3968 bytes — this is the safety net

**Migration safety:** Adding fields at the END of SaveBlock2 is the only safe approach. The save system reads the struct by byte offset; fields added at the end do not shift existing data.

**`struct DynamaxDen` definition** — do NOT define this inline in `global.h`. The struct is declared in `include/raid_den.h` (created by Plan 01-01, which this plan depends on).

**Correct approach:** Add `#include "raid_den.h"` to `global.h` after existing includes, then add the `dynamaxDens` field at the end of `SaveBlock2`. `struct DynamaxDen` will be visible because `raid_den.h` defines it.

**Existing includes in `global.h`** — the file already includes many headers. Add the new include after the existing `#include` block near the top (before the first struct definition), or specifically after whichever include is currently last in the preamble.

**Exact insertion — two changes to `global.h`:**

1. Find the line `#include "constants/flags.h"` (or the last `#include` in the preamble section of global.h) and add `#include "raid_den.h"` after it. If there is no `#include "constants/flags.h"`, add `#include "raid_den.h"` after whichever preamble include comes last before the first struct definition.

2. Find the line (near line 571):
   ```c
       u32 randomizerSeed;
   }; // sizeof=0xF2C
   ```
   Replace it with:
   ```c
       u32 randomizerSeed;
       struct DynamaxDen dynamaxDens[MAX_DYNAMAX_DENS];
   }; // sizeof updated by compiler
   ```

**GBA constraints:** No `malloc`. `gSaveBlock2Ptr` is in EWRAM; accessing `gSaveBlock2Ptr->dynamaxDens[i]` is normal pointer-field access.
