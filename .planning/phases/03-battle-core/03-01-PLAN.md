    gBattlerPositions[0] = B_POSITION_PLAYER_LEFT;

**include/battle.h — GetBattlerSide RAID guard:**

`GetBattlerSide` is a `static inline` at around line 1243 in include/battle.h:

```c
static inline u32 GetBattlerSide(u32 battler)
{
    return GetBattlerPosition(battler) & BIT_SIDE;
}
```

Replace with:

```c
static inline u32 GetBattlerSide(u32 battler)
{
    if ((gBattleTypeFlags & BATTLE_TYPE_RAID) && battler == 3)
        return B_SIDE_PLAYER;
    return GetBattlerPosition(battler) & BIT_SIDE;
}
```

This ensures battler 3 is treated as player-side for all side-dependent logic (party lookup, AI ally detection, UndoDynamax guard in Plan 03-03) despite being assigned B_POSITION_OPPONENT_RIGHT in the position table. No other callers are affected outside BATTLE_TYPE_RAID.

Verify that `gBattleTypeFlags` is visible at the point of this inline (it should be — battle.h already uses it in other macros).
