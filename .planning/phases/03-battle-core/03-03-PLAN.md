  <name>Task 1: Implement SetupRaidBossParty() in src/raid_den.c</name>
  <files>src/raid_den.c</files>
  <action>
Remove the static forward declaration of SetupRaidBossParty added in Plan 03-01 — it becomes the real definition here.

Place the following before DoRaidBattle() so no forward declaration is needed:

```c
static const u8 sStarLevelMin[6] = {0, 15, 25, 35, 45, 55};
static const u8 sStarLevelMax[6] = {0, 20, 30, 40, 50, 60};

static void SetupRaidBossParty(u8 denId)
{
    u16 species = gSaveBlock2Ptr->dynamaxDens[denId].species;
    u8 stars    = gSaveBlock2Ptr->dynamaxDens[denId].starRating;
    u8 minLv, maxLv, level;
    u32 maxHp;

    if (stars == 0 || stars > 5)
        stars = 1;
    if (species == 0)
        species = SPECIES_ZIGZAGOON;  // guard against uninitialized den

    minLv = sStarLevelMin[stars];
    maxLv = sStarLevelMax[stars];
    level = (u8)(minLv + (Random() % (maxLv - minLv + 1)));

    ZeroEnemyPartyMons();
    CreateMon(&gEnemyParty[0], species, level, 31, FALSE, 0, OT_ID_RANDOM_NO_SHINY, 0);

    maxHp = GetMonData(&gEnemyParty[0], MON_DATA_MAX_HP, NULL) * 3;
    SetMonData(&gEnemyParty[0], MON_DATA_MAX_HP, &maxHp);
    SetMonData(&gEnemyParty[0], MON_DATA_HP, &maxHp);

    // Allies MUST go to gPlayerParty[3] and gPlayerParty[4] — not gEnemyParty.
    // Reason: gBattlerPartyIndexes[2]=3 and gBattlerPartyIndexes[3]=4, and the
    // GetBattlerSide guard in include/battle.h returns B_SIDE_PLAYER for battler 3
    // during BATTLE_TYPE_RAID. All battle stat/move/HP reads for battlers 2 and 3
    // therefore index into gPlayerParty. Writing allies to gEnemyParty would cause
    // corrupted reads for every move, HP, and stat lookup on those battlers.
    //
    // Phase 3 limitation: the player's own party must occupy slots 0–2 only.
    // Slots 3 and 4 are unconditionally overwritten here. Enforce this in the
    // test save (and document for Phase 6 when real ally selection is added).
    CreateMon(&gPlayerParty[3], SPECIES_SCEPTILE, level, 31, FALSE, 0, OT_ID_PLAYER_ID, 0);
    CreateMon(&gPlayerParty[4], SPECIES_BLAZIKEN, level, 31, FALSE, 0, OT_ID_PLAYER_ID, 0);
}
```

Check that src/raid_den.c already includes (or add if missing): `pokemon.h` (CreateMon, GetMonData, SetMonData, ZeroEnemyPartyMons), `random.h` (Random), and whatever header exposes gSaveBlock2Ptr (typically `global.h` or `save.h`).

GetMonData's third parameter is a void* output buffer for non-numeric data; for numeric queries it is unused — pass NULL.
