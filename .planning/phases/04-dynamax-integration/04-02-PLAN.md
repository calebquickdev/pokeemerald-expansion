**src/raid_den.c — add TryAdvanceRaidRotation:**

Add the following function before `DoRaidBattle()` (or at the end of the file, before any `#endif`). No `static` — it is called from `battle_main.c`:

```c
void TryAdvanceRaidRotation(void)
{
    static const u8 sRaidRotation[] = {0, 2, 3};
    u32 i;

    for (i = 0; i < ARRAY_COUNT(sRaidRotation); i++)
    {
        if (GetActiveGimmick(sRaidRotation[i]) == GIMMICK_DYNAMAX)
            return;
    }

    switch (gBattleStruct->raid.dynamaxEnergy)
    {
        case 0:  gBattleStruct->raid.dynamaxEnergy = 2; break;
        case 2:  gBattleStruct->raid.dynamaxEnergy = 3; break;
        default:
        case 3:  gBattleStruct->raid.dynamaxEnergy = 0; break;
    }
}
```

The loop checks battlers 0, 2, and 3 (the three player-side slots) — if any is actively Dynamaxed, the rotation does not advance that turn, preserving the current eligible battler for the next turn. The `default: case 3:` handles any unexpected value by cycling back to 0.

**include/raid_den.h — declare TryAdvanceRaidRotation:**

Add the following declaration before `#endif`:

```c
void TryAdvanceRaidRotation(void);
```

**src/battle_main.c — hook in BattleTurnPassed():**

```c
    if (gBattleTypeFlags & BATTLE_TYPE_RAID)

```

`AssignUsableGimmicks()` immediately consumes the updated `dynamaxEnergy` to populate `usableGimmick[]` for the new turn's action selection, so the advance must happen before it.
