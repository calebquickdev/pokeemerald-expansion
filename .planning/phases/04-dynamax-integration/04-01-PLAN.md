Locate the closing `};` of `struct BattleGimmickData` (the struct ending with `bool8 activated[MAX_BATTLERS_COUNT][GIMMICKS_COUNT];`). Immediately after that closing brace, insert:

```c
struct RaidData
{
    u8 dynamaxEnergy;        // index of the battler eligible to Dynamax this turn (0, 2, or 3)
    u8 allyIconSpriteId[2];  // icon sprite IDs for battlers 2 and 3; MAX_SPRITES = sentinel
    u8 shieldHp;             // Phase 5: boss shield units remaining (zeroed this phase)
    u8 respawnTimer[3];      // Phase 5: per-ally faint respawn countdowns (zeroed this phase)
};
```

Then find the `struct BattleStruct` body. Locate the line `struct BattleGimmickData gimmick;`. On the immediately following line, add:

```c
    struct RaidData raid;
```

Do not reorder or remove any existing fields; binary layout depends on declaration order.

  <name>Task 2: Initialize raid fields in InitSinglePlayerBtlControllers RAID branch</name>
  <files>src/battle_controllers.c</files>
  <action>
In `InitSinglePlayerBtlControllers()`, find the `if (gBattleTypeFlags & BATTLE_TYPE_RAID)` block. After these three existing lines:

```c
        SetActiveGimmick(1, GIMMICK_DYNAMAX);
        SetGimmickAsActivated(1, GIMMICK_DYNAMAX);
        gBattleStruct->dynamax.dynamaxTurns[1] = 0xFF;
```

Insert the raid initialization immediately after (before `gBattleMainFunc = BeginBattleIntro`):

```c
        gBattleStruct->raid.dynamaxEnergy = 0;
        gBattleStruct->raid.allyIconSpriteId[0] = MAX_SPRITES;
        gBattleStruct->raid.allyIconSpriteId[1] = MAX_SPRITES;

        memset(gBattleStruct->raid.respawnTimer, 0, sizeof(gBattleStruct->raid.respawnTimer));
```

Placement after the boss gimmick setup is intentional — it avoids any ordering concern if `BattleStruct` is ever partially cleared between steps. `BattleStruct` is already zeroed at battle start by `InitBattleStruct`, so these are explicit documentation of intent as much as functional initialization.

`MAX_SPRITES` is defined in `include/sprite.h`. It is already transitively available in `battle_controllers.c` via `global.h` or `battle.h`. If the compiler complains, add `#include "sprite.h"`.
