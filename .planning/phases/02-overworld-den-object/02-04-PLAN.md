# Plan 02-04: Den Interaction Script and Test Map

## Goal
Add a single Raid Den object event to LittlerootTown (`map.json`) and implement the full interaction script in `scripts.inc`: MAP_SCRIPT_ON_LOAD calls `SetupDynamaxDenObjects`, the den script handles the active path (calls `OpenDenLobbyScreen`), the inactive path (shows "Seems it's a den for DYNAMAX Pokémon to appear..." and optionally prompts Wishing Piece use).

## Context

**LittlerootTown currently has 8 object events** (local IDs 1–8). The den object will be added as the 9th entry (local ID 9), matching the `sDenObjectTable` entry added in Plan 02-03.

**Map JSON object event format** (from existing LittlerootTown entries):
```json
{
    "graphics_id": "OBJ_EVENT_GFX_TWIN",
    "x": 16,
    "y": 10,
    "elevation": 3,
    "movement_type": "MOVEMENT_TYPE_WANDER_AROUND",
    "movement_range_x": 1,
    "movement_range_y": 2,
    "trainer_type": "TRAINER_TYPE_NONE",
    "trainer_sight_or_berry_tree_id": "0",
    "script": "LittlerootTown_EventScript_Twin",
    "flag": "0"
}
```
For the den (inanimate, stationary): `movement_type` = `"MOVEMENT_TYPE_NONE"`, `movement_range_x/y` = `0`. Use `"flag": "0"` (no hide flag; the den is always present — its graphic changes via script, not hide/show).

**Den coordinates:** Place the den at `"x": 7, "y": 3` — the open grass area in the northwest corner of LittlerootTown. Elevation 3 (same as other overworld objects).

**MAP_SCRIPT_ON_LOAD:** LittlerootTown currently uses `MAP_SCRIPT_ON_TRANSITION`, `MAP_SCRIPT_ON_FRAME_TABLE`, and `MAP_SCRIPT_ON_WARP_INTO_MAP_TABLE`. Add `MAP_SCRIPT_ON_LOAD` alongside them. The ON_LOAD handler calls `special SetupDynamaxDenObjects` and `end`.

**Flag logic (review):**
- `FLAG_DAILY_DEN_RAIDED_0` **NOT set** → den is active (fresh, Pokémon available) → open lobby
- `FLAG_DAILY_DEN_RAIDED_0` **SET** → den has been raided, now inactive → show message / Wishing Piece prompt

On a fresh game, daily flags start cleared → dens begin in the active state. To test the inactive path during development, manually set `FLAG_DAILY_DEN_RAIDED_0` via the debug menu or a cheat.

**Script macros used** (all confirmed available in `asm/macros/event.inc`):
- `lock` / `faceplayer` / `release` / `end`
- `goto_if_set FLAG, dest` / `goto_if_unset FLAG, dest`
- `checkitem ITEM, qty` → result in `VAR_RESULT` (TRUE/FALSE)
- `goto_if_eq VAR_RESULT, FALSE, dest`
- `msgbox text, MSGBOX_YESNO` → result in `VAR_RESULT` (YES=1, NO=0)
- `goto_if_eq VAR_RESULT, NO, dest`
- `removeitem ITEM, qty`
- `setvar VAR, value`
- `special FUNCTION` (void)
- `msgbox text, MSGBOX_DEFAULT`

**`ITEM_WISHING_PIECE` constant** is 195 — accessible directly by name in scripts via the constants processing chain.

<task id="2">
  Add the MAP_SCRIPT_ON_LOAD hook and the den interaction script to `data/maps/LittlerootTown/scripts.inc`.

  **Step 1 — Update MapScripts block.** Find:
  ```asm
  LittlerootTown_MapScripts::
  	map_script MAP_SCRIPT_ON_TRANSITION, LittlerootTown_OnTransition
  ```
  Add `MAP_SCRIPT_ON_LOAD` as the first entry (ON_LOAD runs after objects are placed; ON_TRANSITION runs before):
  ```asm
  LittlerootTown_MapScripts::
  	map_script MAP_SCRIPT_ON_LOAD, LittlerootTown_OnLoad
  	map_script MAP_SCRIPT_ON_TRANSITION, LittlerootTown_OnTransition
  	map_script MAP_SCRIPT_ON_FRAME_TABLE, LittlerootTown_OnFrame
  	map_script MAP_SCRIPT_ON_WARP_INTO_MAP_TABLE, LittlerootTown_OnWarp
  	.byte 0
  ```
  Then add the `LittlerootTown_OnLoad` handler immediately after the `.byte 0` line:
  ```asm
  LittlerootTown_OnLoad:
  	special SetupDynamaxDenObjects
  	end
  ```

  **Step 2 — Add the `.set` alias** for the den local ID at the top of the file alongside the existing `.set LOCALID_*` aliases:
  ```asm
  .set LOCALID_RAID_DEN_0, 9
  ```

  **Step 3 — Add den interaction script.** Append at the end of the file:
  ```asm
  LittlerootTown_EventScript_RaidDen_0::
  	lock
  	faceplayer
  	@ FLAG not set = active den (Pokémon available)
  	goto_if_unset FLAG_DAILY_DEN_RAIDED_0, LittlerootTown_EventScript_RaidDen_0_Enter
  	@ FLAG set = raided/inactive den
  	checkitem ITEM_WISHING_PIECE, 1
  	goto_if_eq VAR_RESULT, FALSE, LittlerootTown_EventScript_RaidDen_0_NoItem
  	msgbox LittlerootTown_Text_RaidDen_UseWishingPiece, MSGBOX_YESNO
  	goto_if_eq VAR_RESULT, NO, LittlerootTown_EventScript_RaidDen_0_Decline
  	removeitem ITEM_WISHING_PIECE, 1
  	setvar VAR_0x8000, 0
  	special ActivateDynamaxDen
  	special SetupDynamaxDenObjects
  	msgbox LittlerootTown_Text_RaidDen_Activated, MSGBOX_DEFAULT
  	release
  	end

  LittlerootTown_EventScript_RaidDen_0_NoItem:
  	msgbox LittlerootTown_Text_RaidDen_Inactive, MSGBOX_DEFAULT
  	release
  	end

  LittlerootTown_EventScript_RaidDen_0_Decline:
  	release
  	end

  LittlerootTown_EventScript_RaidDen_0_Enter:
  	setvar VAR_0x8000, 0
  	special OpenDenLobbyScreen
  	release
  	end

  LittlerootTown_Text_RaidDen_Inactive:
  	.string "Seems it's a den for\n"
  	.string "DYNAMAX Pokémon\n"
  	.string "to appear...$"

  LittlerootTown_Text_RaidDen_UseWishingPiece:
  	.string "Would you like to use\n"
  	.string "a Wishing Piece?$"

  LittlerootTown_Text_RaidDen_Activated:
  	.string "A Pokémon appeared\n"
  	.string "in the den!$"
  ```
</task>
