# Plan 02-02: Den Object Event Graphics

## Goal
Create placeholder 16×16 PNG sprites for the Active and Inactive den states, then wire them fully into the object event graphics system: constants, pic tables, `ObjectEventGraphicsInfo` structs, the pointer table, and the palette lookup table in `event_object_movement.c`.

## Context

**Sprite dimensions:** 16×16 pixels, indexed color (4bpp), max 16 colors. The build system (`gbagfx`) converts PNG → `.4bpp` pixel data and extracts the palette to a `.gbapal` file — both land in the same directory as the PNG.

**Both sprites share one palette** (`OBJ_EVENT_PAL_TAG_RAID_DEN = 0x1125`). The active and inactive sprites must use the same 16-color palette. For placeholders, draw the active sprite slightly different (e.g. brighter center pixel) from the inactive one, but ensure both are indexed against the same palette colors.

**Fossil template** — use `gObjectEventGraphicsInfo_Fossil` (at `src/data/object_events/object_event_graphics_info.h:3820`) as the exact model for a 16×16 inanimate object. Key fields:
```c
.tileTag = TAG_NONE,
.size = 128,
.width = 16,
.height = 16,
.paletteSlot = PALSLOT_NPC_SPECIAL,   // unique palette, not a shared NPC slot
.shadowSize = SHADOW_SIZE_S,
.inanimate = TRUE,
.compressed = FALSE,
.tracks = TRACKS_NONE,
.oam = &gObjectEventBaseOam_16x16,
.subspriteTables = sOamTables_16x16,
.anims = sAnimTable_Inanimate,
.affineAnims = gDummySpriteAffineAnimTable,
```

**GFX ID assignments:**
- `OBJ_EVENT_GFX_RAID_DEN_INACTIVE = 241` (current `NUM_OBJ_EVENT_GFX`)
- `OBJ_EVENT_GFX_RAID_DEN_ACTIVE   = 242`
- `NUM_OBJ_EVENT_GFX` bumps from 241 → 243

**Palette tag:** `OBJ_EVENT_PAL_TAG_RAID_DEN = 0x1125` (next after `OBJ_EVENT_PAL_TAG_DYNAMIC = 0x1124`).

**Pointer table end** (`src/data/object_events/object_event_graphics_info_pointers.h:492`):
```c
    [OBJ_EVENT_GFX_OW_MON] = &gObjectEventGraphicsInfo_Follower,
};
```
New entries go before the `};`.

**Palette lookup table** (`src/event_object_movement.c:514`):
```c
    {gObjectEventPal_RubySapphireMay, OBJ_EVENT_PAL_TAG_RS_MAY},
```
New entry goes after this line (before the `#if OW_FOLLOWERS_POKEBALLS` block).

  **Step 1 — Create PNGs:**
