# Plan 02-03: C Specials and Header Declarations

## Goal
Add the three special functions (`SetupDynamaxDenObjects`, `ActivateDynamaxDen`, `OpenDenLobbyScreen`) to `src/raid_den.c`, declare them in `include/raid_den.h`, register them in `data/specials.inc`, add the missing `ObjectEventSetGraphicsIdByLocalIdAndMap` declaration to `include/event_object_movement.h`, and add per-den script flag aliases to `include/constants/flags.h`.

## Context

**`SetupDynamaxDenObjects`:** Called from `MAP_SCRIPT_ON_LOAD`. Iterates a static den-object table, compares each entry's `mapGroup`/`mapNum` against `gSaveBlock1Ptr->location`, and calls `ObjectEventSetGraphicsIdByLocalIdAndMap` with `OBJ_EVENT_GFX_RAID_DEN_ACTIVE` if `FLAG_DAILY_DEN_RAIDED(denId)` is NOT set (fresh/active), or `OBJ_EVENT_GFX_RAID_DEN_INACTIVE` if it IS set (raided/inactive).

**`ActivateDynamaxDen`:** Called from the den interaction script after Wishing Piece removal. Reads den ID from `gSpecialVar_0x8000`. Clears `FLAG_DAILY_DEN_RAIDED(denId)` (making the den active), then calls `RollDynamaxDenPokemon(denId)` and stores the species in `gSaveBlock2Ptr->dynamaxDens[denId]`.

**`OpenDenLobbyScreen`:** Phase 2 stub — intentionally empty. Phase 6 will replace with `SetMainCallback2(CB2_DenLobbyScreen)`. Must compile without warnings.

**Missing declaration:** `ObjectEventSetGraphicsIdByLocalIdAndMap` is defined at `src/event_object_movement.c:2797` but NOT declared in `include/event_object_movement.h`. Its signature:
```c
void ObjectEventSetGraphicsIdByLocalIdAndMap(u8 localId, u8 mapNum, u8 mapGroup, u16 graphicsId);
```
Note the parameter order: `mapNum` comes before `mapGroup` (matches the definition).

**Script flag aliases:** Event scripts can reference C constants from `include/constants/flags.h`. The `FLAG_DAILY_DEN_RAIDED(N)` macro cannot be used in scripts, so per-den aliases are needed there. These must NOT redefine the `FLAG_UNUSED_0x93X` names that were removed in Plan 01-01 — define new named aliases instead.

**Den object table:** A static table in `src/raid_den.c` mapping `(mapGroup, mapNum, localId)` → `denId`. Phase 2 has a single test entry for LittlerootTown, den 0, local ID 9 (LittlerootTown will get the den object in Plan 02-04). `MAP_GROUP` and `MAP_NUM` macros are from `include/constants/maps.h`, which `global.h` already includes transitively.

**Required includes for `src/raid_den.c`** after this plan:
```c
#include "global.h"
#include "raid_den.h"
#include "event_data.h"
#include "event_object_movement.h"
#include "constants/event_objects.h"
```
- `event_data.h` provides: `FlagGet`, `FlagClear`, `VarGet`, `gSpecialVar_0x8000`
- `event_object_movement.h` provides: `ObjectEventSetGraphicsIdByLocalIdAndMap` (once declared in Plan 02-03)
- `constants/event_objects.h` provides: `OBJ_EVENT_GFX_RAID_DEN_*` constants

**`data/specials.inc`** uses `def_special FunctionName` macros. Append the three new specials at the end of the file.

  ```c
  void SetupDynamaxDenObjects(void)
  {
      u8 i;
      u8 mapGroup = gSaveBlock1Ptr->location.mapGroup;
      u8 mapNum = gSaveBlock1Ptr->location.mapNum;
      u16 graphicsId;

      for (i = 0; i < ARRAY_COUNT(sDenObjectTable); i++)
      {
          if (sDenObjectTable[i].mapGroup != mapGroup || sDenObjectTable[i].mapNum != mapNum)
              continue;

          graphicsId = FlagGet(FLAG_DAILY_DEN_RAIDED(sDenObjectTable[i].denId))
                       ? OBJ_EVENT_GFX_RAID_DEN_INACTIVE
                       : OBJ_EVENT_GFX_RAID_DEN_ACTIVE;

          ObjectEventSetGraphicsIdByLocalIdAndMap(
              sDenObjectTable[i].localId,
              mapNum,
              mapGroup,
              graphicsId
          );
      }
  }
  ```
