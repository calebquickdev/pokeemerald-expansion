# Phase 02 Plan 02: Den Object Event Graphics Summary

**One-liner:** 16×16 inanimate den sprites wired into object event graphics pipeline with shared palette tag 0x1125.

## What Was Done

### Task 1: PNG Placeholders + Pixel Data + Pic Tables

Created two 16×16 indexed-color PNG sprites using a Python generation script (deleted after use):
- `raid_den_inactive.png` — gray ring pattern, transparent background (index 0 = #FF00FF)
- `raid_den_active.png` — same ring with yellow/white glow cluster in center 4×4

Both share a 16-color palette; `.4bpp` and `.gbapal` files are generated by `gbagfx` at build time from the inactive PNG.

Registered pixel data and palette in `object_event_graphics.h` (after `gFieldEffectObjectPalette_CaveDust`), and pic tables in `object_event_pic_tables.h` (after `sPicTable_RubySapphireMay`) using `obj_frame_tiles` macro.

### Task 2: GraphicsInfo, Constants, Pointer Table, Palette Registration

Added two `ObjectEventGraphicsInfo` structs at end of `object_event_graphics_info.h`, modeled after `gObjectEventGraphicsInfo_Fossil`:
- `.inanimate = TRUE`, `.tracks = TRACKS_NONE`, `.compressed = FALSE`
- `.paletteTag = OBJ_EVENT_PAL_TAG_RAID_DEN`, `.paletteSlot = PALSLOT_NPC_SPECIAL`
- `.oam = &gObjectEventBaseOam_16x16`, size = 128

Added constants to `include/constants/event_objects.h`:
- `OBJ_EVENT_GFX_RAID_DEN_INACTIVE = 241`
- `OBJ_EVENT_GFX_RAID_DEN_ACTIVE = 242`
- `NUM_OBJ_EVENT_GFX` bumped from 241 → 243
- `OBJ_EVENT_PAL_TAG_RAID_DEN = 0x1125` (next after `OBJ_EVENT_PAL_TAG_DYNAMIC = 0x1124`)

Added extern declarations and pointer table entries in `object_event_graphics_info_pointers.h` (extern after `gObjectEventGraphicsInfo_Follower`, pointer entries before closing `};`).

Registered `{gObjectEventPal_RaidDen, OBJ_EVENT_PAL_TAG_RAID_DEN}` in the palette lookup table in `event_object_movement.c` (after `OBJ_EVENT_PAL_TAG_RS_MAY`, before `#if OW_FOLLOWERS_POKEBALLS`).

## Decisions Made

| Decision | Rationale |
|---|---|
| Shared palette for active/inactive sprites | Both states use identical 16-color palette; gbagfx generates .gbapal from inactive PNG only |
| PALSLOT_NPC_SPECIAL | Matches Fossil inanimate object pattern; den is a unique non-NPC overworld object |
| OBJ_EVENT_PAL_TAG_RAID_DEN = 0x1125 | Follows sequential allocation after 0x1124 (DYNAMIC) |
