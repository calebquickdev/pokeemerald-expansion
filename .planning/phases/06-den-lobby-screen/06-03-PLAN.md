```c
static void Task_LobbyRenderLeft(u8 taskId)
{
    u16 species = gSaveBlock2Ptr->dynamaxDens[sLobbyState.denId].species;
    u8  stars   = gSaveBlock2Ptr->dynamaxDens[sLobbyState.denId].starRating;
    u32 personality = 0;  // fixed personality for consistent silhouette

    switch (gTasks[taskId].data[0])
    {
    case 0:
        AllocateMonSpritesGfx();
        HandleLoadSpecialPokePic(TRUE,
            gMonSpritesGfxPtr->spritesGfx[B_POSITION_OPPONENT_LEFT],
            species, personality);
        gTasks[taskId].data[0] = 1;
        break;
    case 1:
        // HandleLoadSpecialPokePic decompresses asynchronously via DMA.
        // Poll until DMA is not busy before creating the sprite.
        if (IsDma3ManagerBusyWithBgCopy()) break;
        LoadCompressedSpritePaletteWithTag(
            GetMonSpritePalFromSpecies(species, FALSE, FALSE), species);
        SetMultiuseSpriteTemplateToPokemon(species, B_POSITION_OPPONENT_LEFT);
        sLobbyState.bossSpriteId = CreateSprite(&gMultiuseSpriteTemplate, 60, 72, 1);
        // Silhouette: fill all non-transparent palette entries with black.
        {
            u8 palNum = gSprites[sLobbyState.bossSpriteId].oam.paletteNum;
            FillPalette(RGB_BLACK, OBJ_PLTT_ID(palNum) + 1, PLTT_SIZE_4BPP - 2);
        }
        gTasks[taskId].data[0] = 2;
        break;
    case 2:
        // Draw star rating above silhouette. Build star string into a local buffer.
        {
            static const u8 sStar[] = _("★");
            static u8 sStarText[12];
            u8 i;
            u8 *ptr = (u8 *)sStarText;
            for (i = 0; i < stars && i < 5; i++)
            {
                *ptr++ = sStar[0];  // font byte for ★ — use gText literal, not '\x02'
            }
            *ptr = EOS;
            AddTextPrinterParameterized4(0, FONT_NORMAL, 8, 8, 0, 0, sStarText, TEXT_SKIP_DRAW, NULL);
            CopyWindowToVram(0, COPYWIN_GFX);
        }
        gTasks[taskId].func = Task_LobbyMain;
        break;
    }
}
```

Important notes:
- `AllocateMonSpritesGfx()` must be called before `HandleLoadSpecialPokePic`; both are declared in `battle_gfx_sfx_util.h`.
- `GetMonSpritePalFromSpecies(species, FALSE, FALSE)` — second param is `isFemale`, third is `isBackPic`; declared in `pokemon.h`.
- `SetMultiuseSpriteTemplateToPokemon(species, B_POSITION_OPPONENT_LEFT)` — declared in `pokemon.h`.
- Silhouette FillPalette: start at `OBJ_PLTT_ID(palNum) + 1` (skip transparent color 0), size `PLTT_SIZE_4BPP - 2` (14 colors × 2 bytes).
- `IsDma3ManagerBusyWithBgCopy()` is declared in `bg.h`; use it as the async poll guard.
- For the ★ character: use `_("★")` string literal in the font encoding. If ★ is not in the font, use asterisk `_("*")` as a placeholder and note the substitution in the SUMMARY.
- `static u8 sStarText[12]` — 12 bytes is enough for 5 stars + EOS; non-const so the buffer can be written; `static` avoids stack VLA issues on GBA.
- `TEXT_SKIP_DRAW` skips the slow character-by-character draw animation; `CopyWindowToVram` flushes it immediately.
