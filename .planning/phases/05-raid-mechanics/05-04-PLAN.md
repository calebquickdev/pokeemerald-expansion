**src/raid_den.c — implement TryRaidStormTick():**

Add the following function at the end of `src/raid_den.c`, after `OpenDenLobbyScreen`:
```c
bool32 TryRaidStormTick(void)
{
    if (gBattleTurnCounter >= 10)
    {
        gBattleOutcome = B_OUTCOME_PLAYER_TELEPORTED;
        BattleScriptExecute(BattleScript_RaidStormExpired);
        return TRUE;
    }
    gBattleCommunication[MULTISTRING_CHOOSER] = (gBattleTurnCounter == 9) ? 1 : 0;
    BattleScriptExecute(BattleScript_RaidStormMessage);
    return TRUE;
}
```

`gBattleTurnCounter` is already incremented in `ENDTURN_ORDER` before `ENDTURN_RAID_STORM` fires. At turn 9's end, `gBattleTurnCounter == 9` → "unbearable!" message. At turn 10's end, `gBattleTurnCounter == 10` → boss flees. Do NOT use `B_OUTCOME_MON_FLED` — it produces a "mon fled" outcome screen. `B_OUTCOME_PLAYER_TELEPORTED` routes through `HandleEndTurn_FinishBattle` which calls `ReturnFromBattleToOverworld`.

Add includes to `src/raid_den.c` for anything new: `battle_scripts.h` (for `BattleScript_RaidStormMessage`, `BattleScript_RaidStormExpired`), and check `battle_main.h` or `battle.h` provides `gBattleOutcome`, `gBattleTurnCounter`, `gBattleCommunication`, `MULTISTRING_CHOOSER`, `BattleScriptExecute`, and `B_OUTCOME_PLAYER_TELEPORTED`. These are all declared in `include/battle.h`, which is already included.
