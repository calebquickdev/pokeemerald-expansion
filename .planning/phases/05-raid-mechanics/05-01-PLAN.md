With:
```c
struct RaidData
{
    u8 dynamaxEnergy;        // index of the battler eligible to Dynamax this turn (0, 2, or 3)
    u8 allyIconSpriteId[2];  // icon sprite IDs for battlers 2 and 3; MAX_SPRITES = sentinel
    u8 shieldHp;             // boss shield units remaining
```

<task type="auto">
  <name>Task 2: Shield intercept in Cmd_adjustdamage</name>
  <files>src/battle_script_commands.c</files>
  <action>
In `Cmd_adjustdamage` (line 2078), inside the `for (battlerDef = 0; ...)` loop, add the RAID shield intercept block **before** the `DoesSubstituteBlockMove` check (around line 2102) and **before** the Ice Face check (around line 2110). Insert after the `DoesSubstituteBlockMove` continue and the `DoesDisguiseBlockMove` continue, but **before** Ice Face — specifically, insert it immediately after the `continue` for `DoesDisguiseBlockMove` block (after line ~2109):

```c
        if ((gBattleTypeFlags & BATTLE_TYPE_RAID)
         && battlerDef == B_POSITION_OPPONENT_LEFT
         && gBattleStruct->raid.shieldHp > 0)
        {
            u8 consume = IsMaxMove(gCurrentMove) ? 2 : 1;
            gBattleStruct->raid.shieldHp = (gBattleStruct->raid.shieldHp > consume)
                                         ? gBattleStruct->raid.shieldHp - consume : 0;
            gBattleStruct->moveDamage[battlerDef] = 0;
            gBattleStruct->moveResultFlags[battlerDef] &=
                ~(MOVE_RESULT_SUPER_EFFECTIVE | MOVE_RESULT_NOT_VERY_EFFECTIVE);
            continue;
        }
```

`B_POSITION_OPPONENT_LEFT` is the constant value 1 (the boss's battler index in a RAID battle). Using the named constant is required by project conventions.

Do NOT set `MOVE_RESULT_NO_EFFECT` — doing so kills animations and blocks ability effects. Zeroing `moveDamage` while leaving other flags intact is the correct pattern (identical to the Ice Face pattern in this same function).

`IsMaxMove` is defined in `src/battle_dynamax.c` and already declared in a header included by `battle_script_commands.c`. Add `#include "raid_den.h"` to the include block at the top of `src/battle_script_commands.c` so `gRaidCurrentStarRating` is accessible for Plan 02's threshold check (which also lives in this file).
