**src/raid_den.c — add TryRaidAllyRespawn at end of file:**

```c
void TryRaidAllyRespawn(void)
{
    static const u8 sAllyBattlers[] = {0, 2, 3};
    u32 i;

    for (i = 0; i < ARRAY_COUNT(sAllyBattlers); i++)
    {
        u8 battler = sAllyBattlers[i];
        if (gBattleStruct->raid.respawnTimer[battler] == 0)
            continue;
        gBattleStruct->raid.respawnTimer[battler]--;
        if (gBattleStruct->raid.respawnTimer[battler] == 0)
        {
            gBattleMons[battler].hp = gBattleMons[battler].maxHP;
            gAbsentBattlerFlags &= ~(1u << battler);
        }
    }
}
```

Timer lifecycle: respawnTimer starts at 2 when an ally faints. First call to `TryRaidAllyRespawn` (end of the same turn the faint happened): decrements to 1 — ally stays absent, skips that turn's move selection. Second call (next turn): decrements to 0 — HP is restored to `maxHP` and the absent bit is cleared, so the ally participates in move selection starting that turn.

`respawnTimer[battler]` uses direct battler indexing (0, 2, 3), which works because `respawnTimer` was resized to `[4]` in Plan 01. Index 1 (the boss) is never written and stays 0.

`gAbsentBattlerFlags` and `gBattleMons` are accessible from `src/raid_den.c` through the existing `#include "battle.h"` at the top of the file.
